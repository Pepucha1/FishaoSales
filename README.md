# Fishao ceny ryb

Neoficiální přehled cen ryb ze hry [Fishao](https://www.fishao.net/wiki): dnešní cena vs. dlouhodobý průměr, minimum, maximum a vývoj.

- Každý den v 7:00 UTC GitHub Actions stáhne ceny z Fishao Wiki, uloží je do `ceny.csv` a vygeneruje stránku na GitHub Pages.
- `fishao-ceny.ps1` je sběr cen a generování přehledu (Windows PowerShell); `sablona.html` je vzhled stránky.
- `nazvy-cz.csv` a `oblasti.csv` jsou české názvy ryb a oblastí (dají se ručně upravit).
- Ruční spuštění: karta **Actions** → **Fishao ceny** → **Run workflow**.

Názvy, ceny a obrázky ryb patří hře Fishao.
